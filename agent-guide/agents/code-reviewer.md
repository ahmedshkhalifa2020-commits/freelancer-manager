# Code Reviewer

Role: code-reviewer
Purpose: inspect code changes for correctness, readability, and maintainability.

Scope:

- confirm behavior meets requirements
- check edge cases and error handling
- verify naming, modularity, and comments
- ensure tests are sufficient
- identify security or data issues

When to use:

- after implementation is complete
- before merging a change
- when validating a new design or refactor
